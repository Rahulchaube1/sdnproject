# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the OpenFlow 1.3 policy logic, simulator, or web server:
1. Please **do not** report security vulnerabilities through public GitHub issues.
2. Instead, report the vulnerability directly to the project maintainers via email at:
   - Rahul Chaube (`RA2311003012372`)
3. Please include:
   - A description of the vulnerability and attack vector.
   - Exact steps or proof-of-concept payload to reproduce the behavior.
   - Any proposed mitigations or patch suggestions.
4. The maintainers will acknowledge receipt within 48 hours and work on a coordinated fix.
